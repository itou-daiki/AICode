つまずき解説

プログラミングをはじめたばかりの人が、よくつまずくところを集めました。どの例も「▶ 動かす」で 1 行ずつ動かせます。いま動いている行には朱の印がつき、その行が入っているまとまりには朱の線が引かれます。書き方を切りかえて、動き方のちがいを見くらべてください。

困っていることから探せます。

エラーが出て、意味が分からない

  • エラーメッセージの読み方
  • IndentationError → 字下げ
  • NameError → 引用符と名前
  • TypeError（str と int）→ input()

  • 入れかえたのに同じ値 → 入れかえ

何も表示されない・None と出る

  • 関数を呼んでいない・return が無い
  • if の中身がとばされている

いつまでも終わらない

  • 止まらないくり返し

01字下げ（インデント）とまとまり

空白は見た目をそろえるためのもので、あってもなくても同じ。

Python では、行のはじめの空白が「どこまでが中身か」を決めます。字下げを 1 つ変えるだけで、動き方が変わります。

「:」で終わる行が見出し、その下で 4 文字下げた行が中身

if・for・while・def の行は「:」で終わります。この行を「見出し」（まとまりの頭）と呼ぶことにします。その下で 4 文字下げた行が中身です。中身は、字下げを戻した行の手前までつづきます。

if の中身は、条件が成り立たないと、とばされる

x の値を切りかえて動かしてみましょう。中身の行はとばされることがありますが、外の行はいつも動きます。

1 行の字下げで、表示される回数が変わる

print(total) が for の中身か外かで、何回表示されるかが変わります。

入れ子：中にまた見出しがあれば、さらに 4 文字

for の中の for の中身は、合わせて 8 文字下げます。「---」をどの深さに置くかで、表示される回数を見くらべましょう。内側のくり返しは、外側の 1 回ごとに最後まで回ります。

関数の中身は、呼んだときだけ動く

def で作っただけでは、中身は動きません。呼んだときに中身へ移り、終わると呼んだ行にもどります。

まちがい探し

自分で書いて確かめる

書いているうちに、カーソルのある行が「どのまとまりの中か」を下に表示します。Tab キーで 4 文字下げ、Shift + Tab で戻します。

よくあるまちがい

  • 見出しの行のおわりの「:」を書きわすれる。
  • 中身を下げわすれる（IndentationError）。中身が何も無いときは pass と書きます。
  • 同じまとまりの中で 4 文字の行と 2 文字の行をまぜる（IndentationError）。この教材では 4 文字ずつにそろえます。
  • 全角の空白で下げる。全角の空白は使えません（エディタでは打つと半角に直ります）。

02「=」は「入れる」、「==」は「同じか」

x = x + 1 は、数学なら成り立たない式だからおかしい。

Python の = は「右がわを計算して、その値を左の変数に入れる」という命令です。両がわが等しいという意味ではありません。

「同じか」をくらべるときは ==

if の条件で = を書くと、書き方のまちがい（SyntaxError）になります。書き方のまちがいは動かす前に見つかるので、1 行目も動きません。

03変数の入れかえで、値が消える

a = b のあとに b = a と書けば、a と b が入れかわる。

変数に入れなおすと、前の値は上書きされて消えます。先に入れた値をどこかにとっておかないと、入れかえられません。

04input() で受け取った値は文字列

5 と打てば、数の 5 が入る。

input() は、打たれた字をいつも「文字列」として返します。見た目が数でも文字列です。計算やくらべる前に int() で数にします。

  • 文字列どうしの + は「つなげる」です（'5' + '3' は '53'）。
  • 文字列と数は、+ でつなぐことも < でくらべることもできません（TypeError）。
  • == はエラーにならないので気づきにくいところです。'5' == 5 は、文字列と数なので False になります。
  • 小数を受け取るときは float(input()) です。

05引用符の有無と、名前の打ちまちがい

print(さくら) と書けば、さくら と表示される。

引用符（" " か ' '）でかこんだものが文字そのものです。かこまないと、Python は「変数の名前」だと思って中身を探します。

名前は 1 字ちがえば別のもの

  • Print と print、Total と total は別の名前です（大文字と小文字を区別します）。
  • totl のような打ちまちがいも別の名前なので、NameError になります。エラーに出た名前と、作ったときの名前を 1 字ずつ見くらべましょう。
  • 変数は、使う行より上で作っておく必要があります。

06range は終わりの数を含まない、番号は 0 から

range(1, 5) は 1 から 5 まで。リストの 1 番目は a[1]。

range(はじめ, おわり) は、おわりの数の「1 つ手前まで」です。リストの番号は 0 から数えるので、最初は a[0]、最後は a[len(a) - 1] です。

  • range(5) は 0, 1, 2, 3, 4 の 5 個です。「5 回くり返す」ときに使います。
  • 長さ 3 のリストで a[3] と書くと、番号が無いので IndexError になります。

07くり返しの中で、合計を 0 に戻してしまう

合計を使うところの近くに total = 0 を書いておけばよい。

total = 0 がくり返しの中にあると、くり返すたびに 0 に戻ります。合計の準備は、くり返しの前に 1 回だけ書きます。

08print と return はちがう

関数の中で print すれば、その値が関数の答えになる。

print は画面に表示するだけです。関数の答え（呼んだところで使える値）は return で返します。return が無い関数の値は None です。

  • def で作っただけでは、中身は動きません。何も表示されないときは、関数を呼んでいるか確かめましょう。
  • return の行まで来ると、関数はそこで終わります。下に書いた行は動きません。

09止まらないくり返し

while の条件を書けば、いつか終わる。

while は、条件が成り立つあいだずっとくり返します。中身のどこかで条件に使う変数を変えないと、いつまでも終わりません。変える行の字下げもたいせつです。

この教材では、10 秒たっても終わらないプログラムは止めます。止まったら、条件に使っている変数が中身で変わっているかを見ましょう。

10全角と半角

日本語入力のまま打っても、同じ記号なら動く。

プログラムの記号・数字・空白は半角で書きます。全角の（ ）や ：、全角の空白は、Python には別の字に見えます。

  • このエディタでは、打った全角を自動で半角に直します。文字列（引用符の中）とコメントの中はそのままです。
  • 直せずに残った全角には、赤い波線の印がつきます。
  • エラーのときは、全角の字を print【（】x【）】 のように【 】で囲んで示します。
  • 文字列の中なら、全角を使ってかまいません（print("こんにちは、世界")）。

11エラーメッセージの読み方

英語のエラーが出たら、どこが悪いのか分からない。

見るところは 3 つです。「何行目か」「エラーの種類」「その説明」。この教材では、日本語の案内もいっしょに出ます。

× 3 行目でエラーが起きました ← ① どの行か print(totl) ← その行のコード NameError: name 'totl' is not defined ← ② 種類 ③ 説明（totl という名前が無い） → 「totl」という名前は、まだ作られていません。… ← この教材の案内
  • かっこの閉じわすれは「'(' was never closed」と出て、開いたかっこのある行が示されます。その行から下で、閉じるかっこを書きわすれたところを探します。
  • エラーの行より上に原因があることもあります。たとえば NameError のときは、上で変数を作った行の名前の打ちまちがいを疑います。
  • 「全角を半角に直す」のようなボタンが出たら、押すと直ります。
  • よく出る種類：SyntaxError（書き方）、IndentationError（字下げ）、NameError（名前が無い）、TypeError（種類が合わない）、IndexError（番号が無い）、ZeroDivisionError（0 で割った）。

12確かめ方のコツ

  • ステップ実行で 1 行ずつ追う。01 コーディングの「ステップ実行」なら、1 行ごとに変数の値と、その行がしたことが見られます。
  • print で途中の値を見る。くり返しの中に print(i, total) を 1 行足すと、毎回の値が分かります。確かめ終わったら消します。
  • 小さく書いて、こまめに動かす。10 行書いてから動かすより、2〜3 行ごとに動かした方が、どこでおかしくなったか分かります。
  • 自分で答えを予想してから動かす。予想とちがったところが、考えちがいのあるところです。
  • 動いていたところまで戻す。分からなくなったら「元に戻す」で、動いていたところまで戻してやり直します。
  • フローチャートで流れを見る。くり返しや条件の流れが、図で分かります。
