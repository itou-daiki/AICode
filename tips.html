つまずき解説

プログラミングを始めたばかりの人が、よくつまずくところを集めました。どの例も「▶ 動かす」で 1 行ずつ動かせます。今動いている行には朱の印がつき、その行が入っているまとまりには朱の線が引かれます。書き方を切り替えて、動き方の違いを見比べてください。

困っていることから探せます。

エラーが出て、意味が分からない

  • エラーメッセージの読み方
  • IndentationError → インデント
  • NameError → 引用符と名前
  • TypeError（str と int）→ input()

  • 入れ替えたのに同じ値 → 入れ替え

  • 関数を呼んでいない・return が無い
  • if の中身が飛ばされている

いつまでも終わらない

  • 止まらない繰り返し

01インデント（字下げ）とまとまり

空白は見た目を揃えるためのもので、あってもなくても同じ。

Python では、行のはじめの空白が「どこまでが中身か」を決めます。インデントを 1 つ変えるだけで、動き方が変わります。

「:」で終わる行が見出し、その下で 4 文字下げた行が中身

if・for・while・def の行は「:」で終わります。この行を「見出し」（まとまりの頭）と呼ぶことにします。その下で 4 文字下げた行が中身です。中身は、インデントを戻した行の手前までつづきます。

if の中身は、条件が成り立たないと、飛ばされる

x の値を切り替えて動かしてください。中身の行は飛ばされることがありますが、外の行はいつも動きます。

1 行のインデントで、表示される回数が変わる

print(total) が for の中身か外かで、何回表示されるかが変わります。

入れ子：中にまた見出しがあれば、さらに 4 文字

for の中の for の中身は、合わせて 8 文字下げます。「---」をどの深さに置くかで、表示される回数を見比べてください。内側の繰り返しは、外側の 1 回ごとに最後まで回ります。

関数の中身は、呼んだときだけ動く

def で作っただけでは、中身は動きません。呼んだときに中身へ移り、終わると呼んだ行にもどります。

間違い探し

自分で書いて確かめる

書いているうちに、カーソルのある行が「どのまとまりの中か」を下に表示します。見出しの行の終わりに : を書いて Enter を押すと、次の行は自動で 4 文字下がります。まとまりを終えるときは、行のはじめで Backspace を 1 回押すと 1 段もどります。（Tab キーで 4 文字下げ、Shift + Tab で 1 段戻すこともできます）

よくある間違い

  • 見出しの行の終わりの「:」を書き忘れる。
  • 中身を下げ忘れる（IndentationError）。中身が何も無いときは pass と書きます。
  • 同じまとまりの中で 4 文字の行と 2 文字の行を混ぜる（IndentationError）。この教材では 4 文字ずつに揃えます。
  • 全角の空白で下げる。全角の空白は使えません（エディタでは打つと半角に直ります）。

02「=」は「入れる」、「==」は「同じか」

x = x + 1 は、数学なら成り立たない式だからおかしい。

Python の = は「右側を計算して、その値を左の変数に入れる」という命令です。両側が等しいという意味ではありません。

「同じか」を比べるときは ==

if の条件で = を書くと、書き方の間違い（SyntaxError）になります。書き方の間違いは動かす前に見つかるので、1 行目も動きません。

03変数の入れ替えで、値が消える

a = b の後に b = a と書けば、a と b が入れ替わる。

変数に入れ直すと、前の値は上書きされて消えます。先に入れた値をどこかに取っておかないと、入れ替えられません。

04input() で受け取った値は文字列

5 と打てば、数の 5 が入る。

input() は、打たれた字をいつも「文字列」として返します。見た目が数でも文字列です。計算や比べる前に int() で数にします。

  • 文字列どうしの + は「つなげる」です（'5' + '3' は '53'）。
  • 文字列と数は、+ でつなぐことも < で比べることもできません（TypeError）。
  • == はエラーにならないので気づきにくいところです。'5' == 5 は、文字列と数なので False になります。
  • 小数を受け取るときは float(input()) です。

05引用符の有無と、名前の入力ミス

print(さくら) と書けば、さくら と表示される。

引用符（" " か ' '）で囲んだものが文字そのものです。囲まないと、Python は「変数の名前」だと思って中身を探します。

名前は 1 字違えば別のもの

  • Print と print、Total と total は別の名前です（大文字と小文字を区別します）。
  • totl のような入力ミスも別の名前なので、NameError になります。エラーに出た名前と、作ったときの名前を 1 字ずつ見比べてください。
  • 変数は、使う行より上で作っておく必要があります。

06range は終わりの数を含まない、番号は 0 から

range(1, 5) は 1 から 5 まで。リストの 1 番目は a[1]。

range(開始, 終了) は、終了の数の「1 つ手前まで」です。リストの番号は 0 から数えるので、最初は a[0]、最後は a[len(a) - 1] です。

  • range(5) は 0, 1, 2, 3, 4 の 5 個です。「5 回繰り返す」ときに使います。
  • 長さ 3 のリストで a[3] と書くと、番号が無いので IndexError になります。

07繰り返しの中で、合計を 0 に戻してしまう

合計を使うところの近くに total = 0 を書いておけばよい。

total = 0 が繰り返しの中にあると、繰り返すたびに 0 に戻ります。合計の準備は、繰り返しの前に 1 回だけ書きます。

08print と return は違う

関数の中で print すれば、その値が関数の答えになる。

print は画面に表示するだけです。関数の答え（呼んだところで使える値）は return で返します。return が無い関数の値は None です。

  • def で作っただけでは、中身は動きません。何も表示されないときは、関数を呼んでいるか確かめてください。
  • return の行まで来ると、関数はそこで終わります。下に書いた行は動きません。

09止まらない繰り返し

while の条件を書けば、いつか終わる。

while は、条件が成り立つ間ずっと繰り返します。中身のどこかで条件に使う変数を変えないと、いつまでも終わりません。変える行のインデントも重要です。

この教材では、10 秒経っても終わらないプログラムは止めます。止まったら、条件に使っている変数が中身で変わっているかを確認してください。

10全角と半角

日本語入力のまま打っても、同じ記号なら動く。

プログラムの記号・数字・空白は半角で書きます。全角の（ ）や ：、全角の空白は、Python には別の字に見えます。

  • このエディタでは、打った全角を自動で半角に直します。文字列（引用符の中）とコメントの中はそのままです。
  • 直せずに残った全角には、赤い波線の印がつきます。
  • エラーのときは、全角の字を print【（】x【）】 のように【 】で囲んで示します。
  • 文字列の中なら、全角を使ってかまいません（print("こんにちは、世界")）。

11エラーメッセージの読み方

英語のエラーが出たら、どこが悪いのか分からない。

見るところは 3 つです。「何行目か」「エラーの種類」「その説明」。この教材では、日本語の案内も一緒に出ます。

× 3 行目でエラーが起きました ← ① どの行か print(totl) ← その行のコード NameError: name 'totl' is not defined ← ② 種類 ③ 説明（totl という名前が無い） → 「totl」という名前は、まだ作られていません。… ← この教材の案内
  • かっこの閉じ忘れは「'(' was never closed」と出て、開いたかっこのある行が示されます。その行から下で、閉じるかっこを書き忘れたところを探します。
  • エラーの行より上に原因があることもあります。例えば NameError のときは、上で変数を作った行の名前の入力ミスを疑います。
  • 「全角を半角に直す」のようなボタンが出たら、押すと直ります。
  • よく出る種類：SyntaxError（書き方）、IndentationError（インデント）、NameError（名前が無い）、TypeError（種類が合わない）、IndexError（番号が無い）、ZeroDivisionError（0 で割った）。

12確かめ方のコツ

  • 1 行ずつ実行して追う。01 コーディングの「ステップ実行」なら、1 行ごとに変数の値と、その行がしたことが見られます。
  • print で途中の値を見る。繰り返しの中に print(i, total) を 1 行足すと、毎回の値が分かります。確かめ終わったら消します。
  • 小さく書いて、こまめに動かす。10 行書いてから動かすより、2〜3 行ごとに動かした方が、どこでおかしくなったか分かります。
  • 自分で答えを予想してから動かす。予想とちがったところが、考え違いのあるところです。
  • 動いていたところまで戻す。分からなくなったら「元に戻す」で、動いていたところまで戻してやり直します。
  • フローチャートで流れを見る。繰り返しや条件の流れが、図で分かります。
