コード補完の使い方

APIキーが無くても使えます。書いたコードを読み取って候補を出します。

  • 自分で作った変数・関数・クラス
  • import したモジュールの中身
  • 変数の型から分かるメソッド（name. で文字列のメソッド）
  • 組み込み関数と、よく使う書き方のひな形

/

ブロックとコードの関係

ブロックを動かすとコードが変わり、コードを書き換えるとブロックが組み直されます。

ブロックにできない書き方は「Python」ブロックとしてそのまま残るので、どんなコードでも往復できます。

コードだけで書きたいときは ブロックを閉じる を押してください。

じっくりモードとは

すぐに答えが出てしまうと、考える時間がなくなってしまいます。じっくりモードでは：

  • 補完は自動で出さず、CtrlSpace を押したときだけ出ます
  • 実行の前に「出力はどうなる？」と予想を書く欄が出ます
  • 実行後、予想と実際を見くらべて教えてくれます

予想してから実行する進め方は PRIMM（Predict → Run → Investigate → Modify → Make）という学び方にもとづいています。

⏯ ステップ実行とは

プログラムを1行ずつたどって、そのときの変数の値と出力を確かめられます。

実行中は画面が2つに分かれ、左側でコード・フローチャート・ブロックを切り替えられます。
